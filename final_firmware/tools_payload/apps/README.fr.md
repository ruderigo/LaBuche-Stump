# Applis FireFly

Les clients maillés FireFly, à installer depuis ce nœud sans internet. La plus récente de chacune est listée sous Applications dans la page Outils et sur la page À propos.

- `FireFly-Android-<version>.apk` — l'appli Android.
  https://github.com/ruderigo/FireFly-Android
- `FireFly-RK3326-<version>.zip` — pour les consoles portables RK3326
  (R36S, R36MAX).
  https://github.com/ruderigo/FireFly_RK3326_R36MAX_R36S

Un fichier plus récent déposé dans ce dossier remplace l'ancien sur la
page, sans mettre à jour le nœud. L'appli Android pèse environ 50 Mo :
copie-la dans le dossier `tools/firefly/` de la carte avec un lecteur
de cartes (en USB, ça prendrait des heures).
