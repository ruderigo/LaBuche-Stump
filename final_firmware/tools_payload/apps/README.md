# FireFly apps

FireFly mesh clients, to install from this node with no internet. The newest of each is listed under Apps on the Tools page and on the About page.

- `FireFly-Android-<version>.apk` — the Android app.
  https://github.com/ruderigo/FireFly-Android
- `FireFly-RK3326-<version>.zip` — for RK3326 handhelds (R36S, R36MAX).
  https://github.com/ruderigo/FireFly_RK3326_R36MAX_R36S

A newer file dropped in this folder replaces the old one on the page,
with no update to the node. The Android app is about 50 MB: copy it to
the card's `tools/firefly/` folder with a card reader (over USB it
would take hours).
