# Flasheador en el navegador

Lo que usa la página /flash de este nodo para flashear una placa conectada a tu computadora, desde Chrome o Edge, sin instalar nada.

## Qué hay aquí

- `esptool-bundle.js`: esptool-js, el código de flasheo que la página
  /flash carga en tu navegador.
- `esptool-js-LICENSE.txt`: su licencia (Apache-2.0).

No hace falta descargarlos: abre /flash en este nodo. Las imágenes de
firmware que ofrece están en la carpeta `fw/` de la tarjeta.
