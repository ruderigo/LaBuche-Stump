# Flasheur dans le navigateur

Ce que la page /flash de ce nœud utilise pour flasher une carte branchée à ton ordinateur, depuis Chrome ou Edge, sans rien installer.

## Ce qu'il y a ici

- `esptool-bundle.js` — esptool-js, le code de flashage que la page
  /flash charge dans ton navigateur.
- `esptool-js-LICENSE.txt` — sa licence (Apache-2.0).

Pas besoin de les télécharger : ouvre plutôt /flash sur ce nœud. Les
images de micrologiciel qu'elle propose sont dans le dossier `fw/` de
la carte.
